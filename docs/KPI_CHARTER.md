## Success Criteria per KPI

> **⚠ Data Gap:** ไม่มี baseline ปัจจุบันของทั้ง 5 ตัวชี้วัดใน Input Context — ตัวเลข target ทั้งหมดมาจากที่ผู้ใช้ระบุโดยตรง ไม่มีการสมมติเพิ่มเติม ยกเว้นจุดที่ระบุว่าเป็น "Assumption" ด้านล่าง

| KPI_# | Partial (<70%) | Full (100%) | Exceed (>100%) | Unit |
|---|---|---|---|---|
| KPI_1 | ความแม่นยำเฉลี่ย <70% (variance จาก actual >30%) | ความแม่นยำ = 100% (0% variance) ทุกเดือนในไตรมาส | รักษาความแม่นยำ 100% ครบ 3 เดือน **และ** ระบุความเสี่ยงด้าน cash ล่วงหน้าได้อย่างน้อย 1 ครั้ง | % Accuracy |
| KPI_2 | Variance >5% ในเดือนใดเดือนหนึ่ง | Variance ≤5% ทุกเดือน | Variance ≤2% ทุกเดือน | % Variance |
| KPI_3 | ส่งรายงานตรงเวลา (ภายในวันที่ 5 ของเดือนถัดไป) <70% ของรอบ | ส่งตรงเวลา 100% ทุกเดือน (3/3) และไม่มี material error | ส่งตรงเวลา 100% ทุกเดือน + ส่งก่อนกำหนดอย่างน้อย 2 วันในบางเดือน | % On-time Submission |
| KPI_4 | งานที่มอบหมายให้ลูกทีมเสร็จตรงเวลา <70% | งานที่มอบหมายเสร็จตรงเวลา 100% ทุกเดือน | 100% ตรงเวลา + มีหลักฐานพัฒนาทักษะลูกทีมเพิ่มเติม (up-skilling/รับผิดชอบงานใหม่ได้) | % On-time Task Completion |
| iKPI_5 | Completion <70% ณ สิ้นไตรมาส | Deploy และใช้งานได้จริง 100% ภายในกำหนด* | Deploy สำเร็จก่อนกำหนด + validate ได้จริงกับอย่างน้อย 1 use case | % Completion |

*\*Assumption ที่ต้อง confirm: กำหนดส่งมอบ iKPI_5 ตีความจากคำตอบ "ภายในวันที่ 5 ของเดือน" ว่าหมายถึง **5 ตุลาคม 2569** (วันที่ 5 ของเดือนถัดจากสิ้นไตรมาส เช่นเดียวกับ cadence ของ KPI_3) — ถ้าหมายถึงเดือนอื่นหรือ cadence รายเดือน (ระบบต้องพร้อมใช้ทุกวันที่ 5 ของแต่ละเดือนในไตรมาส) กรุณาแจ้งแก้ไข*
