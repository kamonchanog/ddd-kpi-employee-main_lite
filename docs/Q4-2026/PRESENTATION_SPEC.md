## Storytelling Guide

**Q-Start Narrative Arc:** ต่อเนื่องจาก Q3 → target ปรับ realistic ขึ้นตามบทเรียนที่ได้ → iKPI_5 เข้าสู่ไตรมาสตัดสินใจสุดท้าย

**Q-End Narrative Arc:** ผลจริง vs target ที่ปรับใหม่ → decision เรื่อง iKPI_5 → เตรียม Q1/2027

**Data Storytelling Rule:** เหมือน Q3 — ทุก claim ต้องมี data evidence
