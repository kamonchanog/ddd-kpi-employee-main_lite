## Success Criteria per KPI

> **Target ปรับให้ realistic ขึ้นจาก Q3 ตามที่ผู้ใช้อนุมัติ (เผื่อ margin ความผิดพลาด)**

| KPI_# | Partial (<70%) | Full (100%) | Exceed (>100%) | Unit |
|---|---|---|---|---|
| KPI_1 | Accuracy เฉลี่ย <70% | Accuracy ≥95% (variance ≤5%) ทุกเดือน | Accuracy ≥98% ทุกเดือน + flag ความเสี่ยงล่วงหน้า ≥1 ครั้ง | % Accuracy |
| KPI_2 | Variance >5% ในเดือนใดเดือนหนึ่ง | Variance ≤5% ทุกเดือน | Variance ≤2% ทุกเดือน | % Variance |
| KPI_3 | ตรงเวลา <70% ของรอบ | ตรงเวลา ≥90% (อย่างน้อย 2/3 รอบตรงเวลา รอบที่เหลือช้าได้ไม่เกิน 2 วันทำการ) ไม่มี material error | ตรงเวลา 100% (3/3) ไม่มี error | % On-time |
| KPI_4 | งานเสร็จตรงเวลา <70% | งานเสร็จตรงเวลา ≥90% | งานเสร็จตรงเวลา 100% + up-skilling evidence | % On-time Completion |
| iKPI_5 | Accuracy/Adoption <70% | True positive rate ≥80% + ใช้งานจริง validate ≥2 use case | True positive rate ≥90% + ใช้งานจริงทั้งทีม (adoption 100%) | % Accuracy / Use Case Count |
